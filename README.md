> A lightweight, modern component library for visualizing disk usage, storage metrics, and file system layouts.

## Features

* 📊 **Storage Analytics:** Interactive radial charts, progress meters, and partition lists.
* ⚡ **Lightweight:** Zero heavy external dependencies for fast render times.
* ♿ **Accessible:** Built with full keyboard navigation and ARIA support.
